## 通知重构

通知系统现在需要进行重构，无需考虑原来的数据结构、API的兼容性。重构的主要目的是让通知系统更通用，支持后续的业务需求，并支持移动端的通知。

重构内容如下：

1. 发送通知方法CreateNotificationAsync 中NotificationType为枚举，无法根据业务扩展；
2. SendScopeType不支持移动端设备通知
3. 现在的通知功能只实现了web端通知和展示，需要完成移动端的通知和展示
4. 有些通知只在后台管理中可以查看，不需要在用户的通知列表中查看。比如对讲请求，收到通知就打开页面操作，无需在通知列表中显示。

根据上述要求请重新设计新的通知系统，并完善移动端通知业务流程和展示页面。移动消息推送服务已经完成，可直接使用。
